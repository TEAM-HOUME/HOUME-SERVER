## POST /api/v1/price-compare/jobs
**가격비교 Job 생성** · 인증 필요 (Bearer)

| HTTP | code | message | 발생 조건 |
|---|---|---|---|
| 400 | 40036 | 유효하지 않은 상품 URL입니다. | URL 형식 오류, SSRF 위험 IP, 지원하지 않는 쇼핑몰 |
| 403 | 40037 | 접근 불가 상품 URL입니다. | 봇 차단 등으로 스크래핑 불가 |
| 400 | 40038 | 상품 메타데이터를 파싱할 수 없습니다. | 스크래핑 성공했으나 title·thumbnail 누락 |
| 502 | 50026 | eBay 상품 검색에 실패했습니다. | eBay API 호출 실패 |
| 502 | 50027 | 상품 키워드 번역에 실패했습니다. | Gemini 번역 호출 실패 |
| 502 | 50028 | 임베딩 생성에 실패했습니다. | Gemini embedding 호출 실패 (429 포함) |
| 429 | 42901 | 현재 요청이 너무 많습니다. | 비동기 파이프라인 스레드풀 포화 |

> **응답**: 202 Accepted + `jobId` 반환 후 비동기 처리  
> 파이프라인 내부 실패(임베딩·eBay)는 Job `status: FAILED`로 반영되며 별도 에러 응답 없음  
> 위 40036~40038 에러는 동기 구간(스크래핑·검증)에서만 발생

## GET /api/v1/price-compare/jobs/{jobId}
**Job 상태 조회** · 인증 불필요

| HTTP | code | message | 발생 조건 |
|---|---|---|---|
| 404 | 40428 | 비교 Job을 찾을 수 없습니다. | jobId 없음 또는 Redis TTL 만료 (60분) |

### Job status 값

| status | 의미 | 클라이언트 처리 |
|---|---|---|
| `PENDING` | 생성됨, 파이프라인 대기 중 | 폴링 유지 |
| `RUNNING` | 파이프라인 처리 중 | 폴링 유지 |
| `DONE` | 완료, 결과 조회 가능 | 결과 화면 진입 |
| `FAILED` | 파이프라인 오류 | 재시도 유도 UI (동일 URL로 POST /jobs 재호출) |
