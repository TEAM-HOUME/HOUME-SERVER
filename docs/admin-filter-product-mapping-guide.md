# 상품 탭 필터 매핑 가이드

> 어드민 보드에서 상품을 각 필터 카테고리에 노출시키는 방법을 설명합니다.

---

## 필터 카테고리별 등록 방법 요약

| 필터 | 매핑 방법 | 어드민에서 선택할 값 |
|------|-----------|----------------------|
| 침대 | 스타일 태그 | 상위 가구 타입: **BED** |
| 소파 | 스타일 태그 | 상위 가구 타입: **SOFA** |
| 테이블 | 스타일 태그 | 상위 가구 타입: **TABLE** |
| 옷장 | 하위 가구 직접 매핑 | 하위 가구: **CLOSET** |
| 장식장 | 하위 가구 직접 매핑 | 하위 가구: **DISPLAY_CABINET** |
| 의자 | 하위 가구 직접 매핑 | 하위 가구: **CHAIR** |
| 화장대 | 하위 가구 직접 매핑 | 하위 가구: **DRESSING_TABLE** |
| 조명 | 하위 가구 직접 매핑 | 하위 가구: **LIGHTING** |
| 기타 | 하위 가구 직접 매핑 | 하위 가구: **ETC** |

---

## 방법 1 — 스타일 태그로 등록 (침대 / 소파 / 테이블)

상품에 **스타일 태그(Furniture Tag)**를 등록하면 해당 태그의 상위 가구 타입을 기준으로 필터에 노출됩니다.

### 등록 경로
`어드민 보드 → 상품 탭 → 상품 선택 → 스타일 태그 추가`

### 단계별 방법

1. 어드민 보드(`/admin/dashboard`)에 접속한다
2. 왼쪽 사이드바에서 **상품** 탭을 선택한다
3. 등록할 상품을 검색 또는 목록에서 찾는다
4. 상품 상세 페이지에서 **스타일 태그 추가**를 클릭한다
5. 태그 선택 시 아래 기준으로 상위 가구 타입을 선택한다

| 노출할 필터 | 선택할 상위 가구 타입 |
|-------------|----------------------|
| 침대 | BED |
| 소파 | SOFA |
| 테이블 (식탁, 책상, 좌식 포함) | TABLE |

> 스타일 태그는 복수 선택 가능하며, 하나의 상품이 여러 필터에 동시에 노출될 수 있습니다.

---

## 방법 2 — 하위 가구 직접 매핑 (옷장 / 장식장 / 의자 / 화장대 / 조명 / 기타)

상품에 **하위 가구(Furniture)**를 직접 연결하면 해당 가구 기준으로 필터에 노출됩니다.  
스타일 태그 없이도 등록 가능합니다.

### 등록 경로
`어드민 보드 → 상품 탭 → 상품 선택 → 하위 가구 추가`

### 단계별 방법

1. 어드민 보드(`/admin/dashboard`)에 접속한다
2. 왼쪽 사이드바에서 **상품** 탭을 선택한다
3. 등록할 상품을 검색 또는 목록에서 찾는다
4. 상품 상세 페이지에서 **하위 가구 추가**를 클릭한다
5. 노출할 필터에 맞는 하위 가구를 선택한다

| 노출할 필터 | 선택할 하위 가구 |
|-------------|-----------------|
| 옷장 | CLOSET |
| 장식장 | DISPLAY_CABINET |
| 의자 | CHAIR |
| 화장대 | DRESSING_TABLE |
| 조명 | LIGHTING |
| 기타 | ETC |

> 하위 가구도 복수 선택 가능합니다.

---

## 기타 필터 — 최초 1회 셋업 필요

**기타** 필터는 아래 두 조건 중 하나에 해당하는 상품이 노출됩니다.

- **SELECTIVE 타입 하위 가구**에 속하지만 개별 필터(옷장·장식장·의자·화장대·조명)에 해당하지 않는 것  
  (예: MIRROR, WHITE_BOOKSHELF, MOVABLE_TV 등)
- **하위 가구 ETC**에 직접 매핑된 상품

> 위의 `방법 2` 기준으로 **ETC** 하위 가구를 선택하면 **기타** 필터에 노출됩니다.

### ETC 셋업 (최초 1회, 개발팀 또는 DB 관리자 수행)

아래 두 레코드가 DB에 없으면 기타 필터가 동작하지 않습니다.

```sql
-- 1. 상위 가구 타입(ETC) 추가
INSERT INTO furniture_type (name, name_eng) VALUES ('기타', 'ETC');

-- 2. 하위 가구(ETC) 추가 — furniture_type_id는 위에서 생성된 id
INSERT INTO furniture (furniture_name, furniture_name_eng, furniture_type_id)
VALUES ('기타', 'ETC', <위에서 생성된 furniture_type_id>);
```

셋업 완료 후부터 어드민 보드에서 **ETC** 하위 가구를 선택할 수 있습니다.

---

## 주의사항

- 스타일 태그 방법과 하위 가구 방법은 **독립적**으로 동작합니다. 한 상품에 두 방법을 모두 적용해도 됩니다.
- 상품이 어떤 가구에도 매핑되지 않으면 **필터 적용 없이 전체 조회**에서만 노출됩니다.
- **기타** 필터 선택 시 ETC 하위 가구로 직접 매핑된 상품만 확실하게 포함됩니다. SELECTIVE 타입의 나머지 가구(MIRROR 등) 하위 상품도 자동 포함되지만, 어드민이 직접 제어하려면 ETC 매핑 방법을 사용하세요.
